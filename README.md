# HelpDesk Pro

مشروع مقترح لنظام يدير بلاغات الدعم الفني. **الحالة الحالية: تصميم فقط.** لا يوجد تطبيق أو ميزات منفذة حتى الآن.

## لماذا هذا المشروع؟

عندما تصل طلبات الدعم عبر قنوات متفرقة، يصعب تتبع حالتها وما عولج منها. النسخة الأولى المخطط لها تطبيق ويب محلي لفريق داخل جهة واحدة، لاختبار إنشاء بلاغ وعرضه وتغيير حالته وإضافة ملاحظة معالجة، باستخدام بيانات تجريبية خيالية.

لا توجد حسابات أو صلاحيات في هذه النسخة؛ **ليست مناسبة لبيانات حقيقية أو للنشر العام بهذه الحالة**.

## ملفات المشروع

- [PROJECT-PLAN.md](PROJECT-PLAN.md): نطاق النسخة الأولى، قصص المستخدم ومعايير قبولها، والمراحل المقترحة.
- [DESIGN.md](DESIGN.md): الصفحات والبيانات والتحقق وسيناريو التجربة اليدوية.
- [OPEN-QUESTIONS.md](OPEN-QUESTIONS.md): القرارات المحسومة والأسئلة المتبقية قبل التنفيذ.

الخطوة التالية هي مراجعة التصميم والسيناريو اليدوي قبل بدء التنفيذ.
