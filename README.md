# HelpDesk Pro

تطبيق ويب محلي بسيط لإدخال بلاغات دعم فني تجريبية وعرضها وتغيير حالتها. **الحالة الحالية: إنشاء البلاغ وعرضه وتغيير حالته منفذة.**

## لماذا هذا المشروع؟

عندما تصل طلبات الدعم عبر قنوات متفرقة، يصعب تتبعها. يتيح الجزء المنفذ تسجيل بلاغ تجريبي ورؤيته في القائمة وصفحة التفاصيل ومتابعة حالته.

لا توجد حسابات أو صلاحيات؛ **استخدم بيانات خيالية فقط، ولا تنشر التطبيق للاستخدام العام بهذه الحالة**.

## المنفذ الآن

- صفحة قائمة البلاغات مع رسالة عند خلوها، وروابط لإنشاء بلاغ وفتح تفاصيله.
- نموذج إنشاء بعنوان ووصف وتصنيف من «أجهزة، برامج، شبكة، أخرى» واسم مقدم طلب تجريبي. يتحقق الخادم من الحقول وحدودها بعد حذف الفراغات الطرفية، ويعرض الأخطاء مع إبقاء القيم عند الفشل.
- حفظ البلاغات في SQLite داخل `instance/helpdesk.sqlite3`. يولّد النظام رقم البلاغ ووقت إنشائه بتوقيت UTC وحالته الابتدائية «جديد».
- صفحة تفاصيل تعرض بيانات البلاغ المحفوظ. يبقى البلاغ ظاهرًا بعد إعادة فتح التطبيق.
- تغيير الحالة خطوة واحدة فقط: «جديد» ← «قيد المعالجة» ← «تم الحل». تعرض التفاصيل زر الانتقال التالي وحده، ويختفي عند الحل. يتحقق الخادم من الانتقال ويحفظ الحالة في SQLite لتظهر في التفاصيل والقائمة بعد إعادة الفتح.

إضافة ملاحظات المعالجة وعرضها لم يُنفّذا بعد؛ وهما الخطوة التالية.

## التشغيل المحلي

يتطلب Python وFlask وفق `requirements.txt`. من داخل مجلد المشروع:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe app.py
```

افتح `http://127.0.0.1:5000/`. يُنشأ مجلد `instance/` وقاعدة البيانات تلقائيًا، ولا يُدرجان في Git.

لتشغيل الاختبارات:

```powershell
.\.venv\Scripts\python.exe -m unittest -v
```
